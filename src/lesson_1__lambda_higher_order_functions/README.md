## 📘 Урок 1: Лямбды и функции высшего порядка
### 📚 Краткая теория:
Лямбда — это анонимная функция, которую можно передавать как аргумент или сохранять в переменную.

Функция высшего порядка — функция, которая принимает другую функцию как аргумент или возвращает функцию.

В Kotlin лямбды часто используются с коллекциями для удобной обработки данных.


### 📚 Теория: fold и reduce
> fold:
- Принимает начальное значение (initial) и функцию-аккумулятор
- Подходит для случаев, когда результат может быть другого типа или нужна начальная "база"
```Kotlin
inline fun <T, R> Iterable<T>.fold(
    initial: R,
    operation: (R, T) -> R
): R
```

> reduce:
- Берет первый элемент как начальное значение
- Нельзя использовать пустой список (выбросит исключение)
- Результат того же типа, что и элементы
